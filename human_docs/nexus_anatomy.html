THE ARCHITECTURE OF A PROVIDER-AGNOSTIC AGENT HARNESS

Understanding Nexus: From High-Level Vision to Low-Level Invariants

Nexus is a provider-agnostic Python agent harness engineered around absolute context transparency. A single per-workspace daemon owns sessions and turns, feeding four presentation clients through an append-only SQLite event spine, a pure event reducer, and a strictly validated two-tier state machine.

The Core Invariant: "Show everything that matters (every parameter, every output), labelled and readable, never a raw JSON dump, and never hide information from the user that the agent can see."

APPEND-ONLY STORE

The Chrono-Spine Reel

nexus/events.py · ~/.nexus/nexus.db

A precision metallic tape reel that can only wind forward, stamped with an incrementing sequence counter (seq: 001, 002...). Every turn event is appended to a shared SQLite database in WAL mode with BEGIN IMMEDIATE. The log is never mutated; session replay simply rolls through the recorded tape.

PURE REDUCER

The Quartz Reducer Prism

nexus/view/reduce.py → ConversationView

A hexagonal optical quartz prism mounted above the tape. As raw embossed event tape passes underneath, it refracts four distortion-free optical beams to four client viewing ports (Ratatui TUI, GPUI Desktop, CLI stream, Web UI). The prism has zero internal memory, ensuring 100% deterministic projection.

PROTOCOL LOOP

The Geneva Turn Turret

nexus/core/loop.py

A 4-position Geneva indexing turret that steps through turn execution. Crucially, core/loop.py knows only protocols. It imports zero concrete managers, decoupling execution logic from specific storage, providers, or tool dispatchers.

CONTEXT & BUDGET

Context Caliper & Dial Gauge

nexus/context/ · Token Indicator

Station 1's precision caliper measures context history, compacts old turns, and sets the token boundary. The elevated dial gauge measures token window consumption (e.g. 34.2k / 200k) and monitors caching breaklines.

MULTI-MODEL HEAD

Provider Resonator Chamber

nexus/model/ (Claude, GPT, Gemini, Ollama)

Station 2 houses swappable crystal heads for Anthropic, OpenAI, Gemini, and Ollama. It resonates with streaming TextDelta and opaque ThinkingDelta chunks, parsing partial JSON streams via ToolCallAccumulator.

TOOL DISPATCH & SAFETY

Security Gate & Tool Actuators

nexus/tools/ · nexus/tools/permissions.py

Station 3's mechanical safety shutter intercepts tool calls, verifying path containment and human approval policies. Once cleared, Station 4's sliding carriage extends an actuator probe to execute bash jobs, file edits, grep searches, or subagent worktrees.

Mathematical Formalism: TurnState Machine

# From nexus/core/turn.py: Strict Transition Invariants _ALLOWED_TRANSITIONS: dict[str, frozenset[str]] = { "new": frozenset({"awaiting_model", "failed", "cancelled"}), "awaiting_model": frozenset({"awaiting_tools", "completed", "failed", "cancelled"}), "awaiting_tools": frozenset({"awaiting_model", "completed", "failed", "cancelled"}), "completed": frozenset(), # Terminal: frozen "failed": frozenset(), # Terminal: frozen "cancelled": frozenset(), # Terminal: frozen }

Critical State Machine Invariants:

  1. Terminal Immutability: Once a turn reaches completed, failed, or cancelled, it is mathematically impossible to transition. Any attempt raises a TurnStateError.
  2. Assistant Message Persisted First: When transitioning from awaiting_model to awaiting_tools, the assistant message is persisted to SQLite before any tool handling occurs. A crash leaves a dangling ToolUse which resume safely handles.
  3. Atomic Batch Permission: If a model produces 5 tool calls, the state moves to awaiting_permission for the entire batch. A denial cancels the whole batch, preventing partial execution bugs.
  4. Manifest Pinning: The loop pins exactly one extension generation per iteration. A tool written mid-iteration is only callable in iteration $N+1$.
03

Strict One-Way Architectural Layering (L0 to L5)

Nexus enforces strict downward-only import rules verified by automated test suites (tests/test_layering.py and tests/test_ui_layering.py). A lower layer never imports a higher one.

L5
UI Surfaces Layer (nexus/ui/, nexus/ui_support/, nexus/client/)

Presentation only: Native Ratatui TUI, Rust GPUI Desktop, One-shot CLI & JSONL stream, Web app. Prohibited from touching database files or importing managers directly.

L4½
Host Subsystem (nexus/host/, nexus/host_support/, nexus/observability/)

The only public surface API: HostFacade, Supervisor (turn FIFO queue & limits), Presence (first-responder approvals), and UDS Daemon.

L4
Runtime Composition Root (nexus/runtime.py)

Instantiates and coordinates all concrete managers, providers, routers, and extension hot-reloading.

L3
Domain Managers (session/, context/, tools/, skills/, mcp/, agents/, hooks/, voice/)

Concrete implementations of domain capabilities: session storage, context budgeting, sandboxed tool execution, skill resolution, and MCP clients.

L2
Core Execution Loop (nexus/core/loop.py, turn.py, bus.py, cancel.py)

Protocol-isolated turn loop. Imports ZERO concrete managers; interacts strictly via protocol interfaces.

L1
Model System (nexus/model/)

Message IR, Provider Protocol, Streaming Event parser, ModelRouter, Tiers, and adapters (Anthropic, OpenAI, Gemini, Ollama, DeepSeek).

L0½
Pure View Reducer (nexus/view/reduce.py, nexus/view/model.py)

Imports only events.py. Folds the monotonic event stream into an immutable ConversationView without I/O or side-effects.

L0
Primitives (config/, errors.py, events.py, util.py)

Immutable event envelopes, path configuration, error hierarchies, and core utilities.

The Five Core Contracts

Five explicit, frozen contracts govern all data boundaries across the entire system.

# Contract Location Essence & Key Invariants
1 Message IR model/message.py Text, Thinking(signature), ToolUse, ToolResult, Image, Document. Role is strictly user | assistant (no system role in IR; context manager injects system text into provider adapters). Thinking.signature is opaque and replayed verbatim.
2 Provider Protocol model/provider.py name, capabilities(model), stream(req), count_tokens(req), aclose(). The core loop inspects capabilities dynamically and adapts without hardcoding.
3 Stream Events model/stream.py MessageStart, TextDelta, ThinkingDelta, ThinkingEnd, ToolCallStart/Delta/End, Usage, MessageStop. ToolCallAccumulator stitches partial JSON fragments.
4 Tool Contract tools/spec.py ToolSpec (declaration schema + harness fields) and ToolExecutionResult. ToolContext intentionally lacks access to the Runtime to preserve sandbox isolation.
5 Event Envelope events.py Event(type, data, seq, ts, session, turn, id). Monotonic seq per session is the append-only spine. Everything reduces from this.

Subsystems & Capabilities: Deep-Dive Details

Exhaustive breakdown of every major capability built into Nexus.

SUBSYSTEM 1

Multi-Model Routing & Tiers

Seamlessly routes requests across Anthropic Claude (3.7 Sonnet, Haiku), OpenAI (GPT-4o, o1, o3-mini), Google Gemini (2.0 Flash, 1.5 Pro), Ollama, and OpenRouter. Semantic tiers (fast, balanced, reasoning) decouple scripts from hardcoded model IDs. Supports opaque thinking signature capture and verbatim multi-turn replay.

SUBSYSTEM 2

Managed Tool Harness & Sandboxing

Built-in tools for file reading, writing, precise contiguous line replacements, ripgrep regex searching, git inspection, and sandboxed bash execution with interactive standard input piping. Long-running shell commands run as background tasks with manage_task handles.

SUBSYSTEM 3

Autonomous Subagents & Worktrees

Sessions can spawn child subagents (invoke_subagent) with dedicated sessions and isolated Git worktrees (branch or share), preventing parallel experiments from dirtying the main working tree. Inter-agent communication is handled via send_message.

SUBSYSTEM 4

Model Context Protocol (MCP)

First-class native MCP client support connecting to local stdio and remote SSE servers. Discovers external tools, prompts, and resources, exposing them directly into the agent's structured tool schema.

SUBSYSTEM 5

Skills & Hot-Reloading

Reusable markdown instructions and procedural playbooks under .agents/skills/. Editing skills, hooks, or settings.toml takes effect immediately in the next turn iteration without restarting the daemon.

SUBSYSTEM 6

Voice Dictation & Realtime Live Audio

Integrated local speech-to-text dictation via Whisper, alongside experimental full-duplex real-time bidirectional audio calls using OpenAI Realtime voice over WebSockets.

SUBSYSTEM 7

Durable Persistence & Replay Matrix

Shared SQLite database (~/.nexus/nexus.db) in WAL mode with synchronous=FULL. Writes in BEGIN IMMEDIATE prevent concurrency races across multiple workspace daemons. Crash recovery is deterministic because all views derive from the append-only event stream.

SUBSYSTEM 8

Multi-Surface Architecture

Four distinct surfaces connect to the same daemon: Native Ratatui TUI client (Rust presentation with schema-3 deltas), Rust GPUI desktop client (owned presentation snapshots), One-shot CLI & JSONL stream, and Web client.
