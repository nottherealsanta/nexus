Caching the manifest

The loader re-reads nexus.json on every call. We memoize _parse_manifest on the file’s mtime, so edits still show up; see src/nexus/loader.py:12 and the design notes.

What changed

  • Added @lru_cache keyed by path and mtime
    • cache size is 8 entries
    • cleared by Loader.reload()
  • Moved the parse into a module-level function

Checklist

  • Regression test counts parses
  • Both tests pass
  • Update the changelog
